
# 📈 QuantA | 个人量化探索助手 🚀

> **QuantA** 是一款基于 **Go** 与 **Vue 3** 构建的跨平台量化交易桌面应用。
> 它旨在通过本地化的方式，为个人交易者提供一个流畅、可控的策略回测与数据分析平台。✨

---

## ✨ 核心特性 (Features)

* **🏗️ 跨平台原生架构**：利用 **Wails v2** 将 Go 的高性能后端与 Vue 3 的现代前端结合，打包出真正独立运行的桌面客户端，拒绝浏览器标签页的凌乱！
* **📊 多指标策略回测**：内置 **MACD、BOLL、RSI、SMA、KDJ** 五种核心技术指标，支持自定义参数快速回测。
* **⚡ 实时数据获取**：通过腾讯代理接口实时获取 A 股历史 K 线数据，支持前复权处理。
* **🛠️ 极简前端交互**：采用 **Vue 3** 响应式框架，支持动态参数配置，操作反馈毫秒级响应。
* **🔒 数据主权**：所有数据和策略代码均保存在 **本地**，无需担心策略泄露或云端限制。

---

## 🛠️ 技术栈 (Tech Stack)

| 模块 | 技术选型 | 作用 |
| --- | --- | --- |
| **Backend** | 🐹 **Go (Golang)** | 核心逻辑、指标计算、进程间通信 |
| **Frontend** | 🖖 **Vue 3** | 用户交互界面与状态管理 |
| **Bridge** | 🌉 **Wails** | 前后端通信桥梁，实现本地窗口调用 |
| **Analysis** | 📊 **go-talib** | 技术指标计算引擎（MACD, RSI, BOLL等） |
| **Data Source** | 💻 **腾讯代理接口** | A 股实时 K 线数据获取 |

## 🚀 快速开始 (Quick Start)

### 📦 开发环境要求

* **Go** (1.20+) 🐹
* **Node.js** (LTS) 🟢
* **Wails CLI** 🏗️

### 🛠️ 安装与运行

1. **克隆仓库**
```bash
git clone https://github.com/Tianjiu/QuantA.git
cd QuantA

```


2. **启动开发环境**
```bash
wails dev

```


3. **构建生产版本**
```bash
wails build

```
